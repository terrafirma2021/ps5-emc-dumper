# Third-party components and references

The release binary is produced with external PS5 SDK and graphics components
that are not vendored in this repository. Their upstream licenses apply.

- ps5-payload-sdk: <https://github.com/ps5-payload-dev/sdk>
- Dear ImGui: <https://github.com/ocornut/imgui>
- PS5 OpenGL tooling: use the source and license supplied with your build tree
- Community label reference: <https://github.com/apewalkers/PS5_NOR_Decode>
- Community label reference: <https://github.com/Liams-Electronics-Lab/PS5-Error-Codes->

No Sony firmware, encryption keys, or decrypted proprietary system modules are
included.
